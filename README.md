## 📱 Sobre o app

**Mini Bio** é um app em **React Native + Expo** com três elementos: meu nome em destaque, minha foto e uma mini bio de um parágrafo.

É uma atividade acadêmica, feita para praticar componentes básicos do React Native, estilização e publicação com **EAS Update (over-the-air)**.

## 🙋 Sobre mim

- 🎓 Cursando Ciência da Computação na Universidade Católica de Pernambuco
- 💻 Interesse em desenvolvimento de software, com foco em **Java**
- 🤝 Participo do Projeto Padawan, mentoria de veteranos para calouros
- 🎯 Objetivo: conseguir meu primeiro estágio na área de TI

## 🛠️ Tecnologias

| Tecnologia | Uso |
|---|---|
| React Native | Interface do app |
| Expo / Expo Go | Desenvolvimento e testes no celular |
| EAS Update | Publicação over-the-air |

## ▶️ Como rodar

```bash
cd meu-app
npm install
npx expo start
```

Escaneie o QR code com o **Expo Go** no celular.
